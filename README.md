E-Commerce Data Analysis Using SQL

Project Overview
This project focuses on analyzing e-commerce data using SQL queries. The main objective is to extract, organize, and analyze structured data to generate useful business insights.

Objective
To learn SQL operations and perform data analysis using database queries.

Tools Used
- Microsoft SQL Server 2025 Express
- SQL Server Management Studio (SSMS)

Dataset
E-Commerce SQL Database

The database contains sample e-commerce information such as:
- Customers
- Products
- Orders
- Order Details
 SQL Concepts Covered

1. SELECT, WHERE, ORDER BY, GROUP BY
2. INNER JOIN, LEFT JOIN, RIGHT JOIN
3. Subqueries
4. Aggregate Functions – SUM(), AVG(), COUNT()
5. Creating Views for Analysis
6. Query Optimization using Indexes

 Business Analysis
- Calculate total sales revenue.
- Identify top-selling products.
- Analyze customer orders.
- Calculate average order value.
- Analyze sales by product category.
- Identify monthly sales trends.

 Project Files

- `ecommerce_database.sql` – Database and table creation.
- `sql_queries.sql` – SQL queries for data analysis.
- `screenshots/` – Screenshots of query outputs.
- `README.md` – Project documentation.

## Outcome
Learned how to manipulate, retrieve, and analyze structured data using SQL. Practiced joins, subqueries, aggregate functions, views, and indexes to generate meaningful business insights.
